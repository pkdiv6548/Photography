# Golden Films

Premium cinematic photography and videography portfolio for Sunil.

## Current status
The first frontend foundation is being built on a feature branch. This is a bilingual (English/Hindi) React + TypeScript prototype with a premium cinematic visual direction and clearly marked demo imagery.

## Development
```bash
npm install
npm run dev
npm run typecheck
npm run build
```

## Planned architecture
- React + TypeScript + Vite frontend
- Cloudflare Workers backend
- Cloudflare D1 database
- Cloudflare R2 media storage, subject to free-tier and billing verification
- GitHub feature-branch and Pull Request workflow
- Postman API and regression testing

## Budget requirement
The project must remain at ₹0. Do not enable paid plans, subscriptions, or billing without explicit approval. Prefer free-tier-compatible designs and document any feature that must be deferred due to free-tier limitations.

## Demo media
All placeholder/demo media must be clearly labeled as sample content and must not be represented as Sunil's real work. Current remote sample images are temporary; check source terms and replace with licensed, generated, or owner-provided assets before production launch.

## Prototype limitations
- Contact details have not yet been supplied.
- The enquiry form is not connected to a backend and does not save enquiries.
- No Admin authentication or production API is implemented in this frontend foundation.
- No Cloudflare resources or production deployment are included in this change.
